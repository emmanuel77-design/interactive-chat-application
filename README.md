# Interactive Chat Application

A simple interactive chat application built with HTML, CSS and JavaScript. The project allows users to type messages and receive automated bot replies in a clean chat-style interface.

This project was created to demonstrate front-end development skills, DOM manipulation, responsive design and basic user interaction handling.

## Features

- Clean chat interface
- User message bubbles
- Automated bot responses
- Responsive design for mobile, tablet and desktop
- Input validation to prevent empty messages
- Auto-scroll to the latest message
- Lightweight project with no external libraries
- Runs directly in the browser

## Technologies Used

- HTML
- CSS
- JavaScript

## How It Works

The user types a message into the input field and clicks the send button. JavaScript captures the input, displays the user message in the chat window and then generates a simple automated response from the bot.

The app uses basic JavaScript functions to create message elements, update the page dynamically and keep the conversation area scrolled to the latest message.

## How to Run

No installation is needed.

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The chat app will open in your browser.

You can also open it using VS Code Live Server.
